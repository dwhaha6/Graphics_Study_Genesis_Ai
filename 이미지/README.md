# 보고서 이미지 정리 규칙

- 보고서 파일명의 날짜를 기준으로 `YYYY-MM-DD/`에 보관합니다. 본문 작성일과 다르면 파일명 날짜를 사용합니다.
- 여러 보고서가 공유하는 이미지는 가장 이른 보고서 날짜에 한 번만 보관하고 함께 참조합니다.
- 보고서에서 참조하지 않아 날짜를 확인할 수 없는 이미지는 `미분류/`에 보존합니다.
- 새 이미지 경로 예: `./이미지/2026-09-10/first_image.png`. Markdown 이미지와 HTML `img` 모두 같은 규칙을 사용합니다.
